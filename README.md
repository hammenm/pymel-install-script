# Install pymel script
## Usage

Here are the steps :
1. Download the file named `install_pymel_Maya2024.bat`.
2. Within the windows file explorer, navigate to the folder where you downloaded the file.
3. On the file do a shift + right-click.
4. In the contextual menu click "Run as administrator"
5. Wait for the script to finish execution
6. You are ready to go. Let's do a happy dance!

## Notes

Only available for Maya2024 on Windows with default installation path
